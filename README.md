# An Ethical Review of Credit Xpress

## Summary

This repository contains an ethical review of Credit Xpress, a moneylender mobile app that provides personal loans to residents in Malaysia. The app is analysed using the SE Code of Ethics and ethical theories such as Deontology, Care Ethics, and Utilitarianism. This review found four issues that violate the SE Code of Ethics:

- Out-of-context location collection.
- Unwarranted repetition of permission requests.
- Hidden information regarding annual borrowing rate.
- Lack of information regarding moneylender's identity, lack of technical support, and poorly documented links.

This report shows that the app disregards user privacy, app transparency, and user consent. This is part 1 of our COMP3041 Professional Ethics in Computing coursework.
